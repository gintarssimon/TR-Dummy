`Inter-latin.woff2` ist die variable Schrift **Inter** (Latin-Subset, Gewichte 100–900) von Rasmus Andersson,
lizenziert unter der SIL Open Font License 1.1 (https://openfontlicense.org), bezogen über das npm-Paket
`@fontsource-variable/inter`. Sie wird beim Build als Base64 in die `index.html` eingebettet.
